-- configure aws cli default profile
aws configure

-- and then provide access key and secret, others are optional

-- to validate aws cli credentials, check to ~/.aws/credentials

-- configure a named profile, ex awsdemo
aws configure --profile awsdemo

-- use aws cli with awsdemo profile, ex:
aws s3 ls --profile awsdemo

Here are some of the important commands under s3:
- Listing objects and folders - ls
- Copying files - cp
- Moving objects or folders - mv
- Deleting objects or folders - rm
- Creating bucket - mb
- Removing bucket - rb

IAM Identities - are users, groups, and roles that are used to define and manage access and permissions to aws services

Roles vs Groups - users are assigned to groups and services (ie. EC2) are assigned to roles, in both cases the attached policies define
what they can do
