[Instructions and Code] Reading and Writing Bookmark using s3

Let us go through s3 APIs to read and write bookmark details using s3. For now we 
will maintain the last copied file as a bookmark.

Writing content to s3. We will use s3://itv-github/sandbox/bookmark.

bookmark_contents = '2021-01-30-0.json.gz'
 
s3_client.put_object(
    Bucket='itv-github',
    Key='sandbox/bookmark',
    Body=bookmark_contents.encode('utf-8')
    )
